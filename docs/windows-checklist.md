# Проверка Posta на Windows 11

Дата: 2026-10-19.

1. Установить NSIS 0.2.0 или распаковать ZIP целиком и открыть Posta.exe.
2. Проверить окно на 100%, 125% и 150% масштабирования Windows: все три колонки, кнопки управления окном, изменение ширины списка, прокрутку.
3. Подключить по одному тестовому/личному ящику iCloud, Gmail и Яндекса, вводя секреты исключительно в приложении. Проверить, что новые письма приходят без ручного обновления.
4. Сравнить входящие с веб-почтой, отметить письмо прочитанным и флажком; проверить изменение в веб-почте.
5. Проверить поиск по теме и отправителю, непрочитанные, смарт-ящик с условием по дате, отдельные аккаунты и разговоры.
6. Открыть HTML-письмо, письмо с inline-фотографией, PDF/другое вложение. Сохранить вложение и сравнить размер с исходным.
7. Отключить интернет, прочитать уже открытое письмо. Восстановить сеть: приложение должно переподключиться без повторного добавления аккаунта.
8. Закрыть окно: значок должен остаться в трее, получение и уведомления должны продолжаться. Открыть через трей. Проверить полное завершение.
9. Перезапустить приложение и проверить сохранение аккаунтов и кэша. Отключить тестовый аккаунт в настройках: его локальные письма исчезают, серверные сохраняются.
10. Microsoft 365 проверять после регистрации client ID и разрешения IMAP администратором. Локальный Exchange Server не поддержан.

Не присылать пароли, токены, файл mail-store.json или содержимое личных писем в чат. При проблеме достаточно шага воспроизведения и текста ошибки без секретов.

Дополнительно для 0.2.0:

- На чистом запуске нет демонстрационных аккаунтов. После подключения появляются папки именно этого аккаунта.
- Открыть Спам, Удалённые, Отправленные и пользовательскую папку. Сравнить с веб-почтой; переместить тестовое письмо в Удалённые и вернуть через «Переместить». Не очищать корзину.
- Создать смарт-ящик с двумя условиями, проверить все/любое, дату и исключение спама. Отредактировать, перезапустить, затем удалить только смарт-ящик: письма должны сохраниться.
- Нажать «Обновить все папки» в смарт-ящике и проверить выборку. Она включает только загруженную часть истории.
- Подготовить письмо на свой тестовый адрес, добавить Копию/Скрытую копию и небольшой файл. Отправить вручную. Проверить получение и единственную копию в Отправленных.
- Проверить Ответить, Ответить всем и Переслать письмо с файлом.
- Создать черновик с вложением, сохранить, перезапустить приложение и продолжить редактирование через «Черновики на ПК».
- При ошибке SMTP черновик должен сохраниться. При успешном SMTP и ошибке сохранения копии должно быть предупреждение о подтверждённой отправке без повторной доставки.
